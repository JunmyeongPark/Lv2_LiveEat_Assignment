*입력 크기 비교: 320x256 vs 640 (Raspberry Pi 4, perception_master)*
결론: *NCNN + 320x256 + 스레드 3* → 640x480 대비 추론 −75%, FPS ×3.0, 출력 동일

```
              320x256 (t3)   640x480 (t3)   차이
추론 평균      103.5 ms       417.1 ms       -75%
발행 FPS       6.89           2.27           x3.0
CPU            201%           240%           -39%p
메모리 RSS     162 MB         225 MB         -62 MB
검출/score     100% / 0.908   100% / 0.906   같음
```

• 속도: 같은 세션·스레드 4끼리도 131 vs 467 ms(−72%), 픽셀 수 비율(3.75배)과 비슷
• 정확도: 약 1.1 m에서 검출 100%, score·위치·거리 동일 (위치 차이 ≈0.06 px)
• 스레드: 320x256은 스레드 4가 3보다 느림(131 vs 104 ms) — 카메라 노드와 CPU 경쟁
• 다음 병목: 프레임마다 35~100 ms를 color·depth 짝 대기에 씀 → 정렬·ROS 동기화는 원인 아님(PC 실험). Pi에서 카메라 토픽 실제 Hz 확인 필요
• 한계: 설정당 1회(약 56초) 측정 / 640x640은 다른 세션(1.3 m)에서만 / 320x256은 1.1 m만 확인
